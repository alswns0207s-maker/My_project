# AirGesture 최종 보고서 정리

첨부된 팀 최종 결과보고서의 구현 결과와 측정 조건을 읽어 정리했습니다. 수치 별로 보고서에 적힌 분모와 환경을 표시합니다.

| 확인 항목 | 팀 보고서 결과 | 조건과 해석 |
| --- | --- | --- |
| 인식 처리율 | 평균 16.3 fps | 팀 시연 당시 인식 측정. 25 fps 미리보기 목표값과 별개 |
| 정지 자세 | 성공률 98.7% | 정지 자세 3종, 50 cm 중심·모서리와 1 m 중심, 1.5 m 중심의 4조건, 총 75회 |
| 명령 중복 | 1/80회 | 명령 제스처 80회 시도 |
| 비의도 명령 | 2회/분 | MEDIA·PPT의 비의도 동작 시험 |
| 음량 UP/DOWN | 75% → 88% | 규칙 판정과 규칙+MLP 보정을 비교한 팀 기록. 비교 표본 수는 보고서에 기재되어 있지 않음 |

## 기능 범위

- 동영상 재생·정지, 음량, 다음·이전 제어를 확인했습니다.
- PowerPoint 다음·이전 이동은 팀 보고서에서 부분 달성으로 표시했습니다.
- 정밀 Air Drawing은 포인터 떨림으로 보고서의 목표에 도달하지 못했습니다. 배포 소스에는 별도의 MOUSE 모드가 있습니다.
- 보고서의 기술 슬라이드에는 개발 중 사용한 손목 각도 방식이 나옵니다. 최종 제출 소스의 기본 판정은 OK 진입, 손바닥의 가로 변위, 중앙 복귀를 사용합니다.

스와이프 MLP를 녹화 클립으로 평가한 별도 결과는 [학습 결과](../training/swipe/training-results.ko.md)에 있습니다.

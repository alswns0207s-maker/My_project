# Raspberry Pi 가위바위보 인식 실습

MediaPipe가 낸 손 관절을 이용해 두 사람의 가위·바위·보를 판정하는 웹 앱 실습입니다. 손 관절을 **222개 특징**으로 바꾸고, Colab에서 학습해 TFLite로 내보낸 모델이 가위·바위·보·기타 네 가지를 분류합니다. 여러 프레임의 판정을 안정화한 뒤 게임 상태에 반영합니다.

## 코드와 학습 파일

| 파일 | 역할 |
| --- | --- |
| [Colab 추가 학습](Colab_RPS_추가학습.ipynb) | 수집한 특징 데이터 읽기, 학습·검증, TFLite 내보내기 |
| [Colab 모델 검증](Colab_모델검증.ipynb) | 제출용 모델과 평가 데이터 점검 |
| [수집기](collector.py) · [특징 계산](training_features.py) | 카메라와 랜드마크에서 학습용 수치 생성 |
| [분류기](custom_classifier.py) · [모델](models/rps_custom.tflite) | Pi에서 학습 모델로 추론 |
| [웹 앱](main.py) · [게임 상태](game.py) | 카메라, 판정 안정화, 라운드와 점수 처리 |

노트북은 코드 셀과 실험 설명을 제공합니다. 수집 영상·관절 좌표는 각자 준비합니다. `model_utils.py`는 기본 손 검출에 필요한 MediaPipe 공식 모델을 내려받아 추출합니다. 저장소에는 이 실습에서 학습해 내보낸 TFLite 모델과 계약 JSON을 포함했습니다.

## 실행

Raspberry Pi OS Bookworm 64비트와 Python 3.11을 대상으로 합니다.

```bash
bash setup.sh
bash run.sh
```

실행 후 Pi의 포트 8501에 접속합니다. 설치의 모델 확인은 222차원 합성 입력에 대해 네 클래스 점수가 나오는지 점검합니다. 모델 품질 평가는 수집한 데이터를 사용해 노트북에서 실행합니다.

## 기존 평가

3회차 평가에서 손이 검출된 **1,125개 표본**을 사용했고, 보류를 실패로 계산한 정답률은 **83.82%**였습니다. 한 참가자의 촬영 기록이며 카메라가 손을 검출하지 못한 경우와 실제 양손 경기 판정은 별도로 평가해야 합니다.

게시용 Python 테스트 18개를 통과했습니다. Raspberry Pi에서 카메라부터 게임 화면까지 연결하는 검증은 해당 보드 환경에서 수행합니다.
